Frequently Asked Questions

Why do you need an Invisible Space? ›
Instagram, TikTok, and Facebook often remove normal line breaks. Our invisible Unicode character (U+2800) forces a clean line break so captions keep the spacing you want.
What is the Caption Counter and how does it help? ›
Caption Counter shows character, word, line and emoji counts and compares them to platform limits (Instagram, YouTube, TikTok). Useful for avoiding truncated captions and keeping descriptions under limits.
How accurate is the Safe Zone Overlay? ›
The Safe Zone Overlay approximates typical UI placements (bottom caption bars, right-side buttons). It’s a visual guide — device variations exist, but it prevents the most common placement issues.
When should I use the Full Frame Blur tool? ›
Use Full Frame Blur to add blurred fill behind portrait content when your source aspect ratio doesn’t match the destination (e.g., post a horizontal photo in a vertical feed), or to hide sensitive background details.
How does Hashtag Cleaner format tags? ›
Paste a block of hashtags; the tool removes duplicates and stray characters, ensures each tag has a single leading “#” and outputs a tidy, copy-ready list for captions.
What does the YouTube Thumbnail Previewer do? ›
This tool simulates multiple thumbnail sizes (desktop large, desktop small, mobile) so you can check whether titles and faces remain legible at small sizes before uploading.
How does Instagram Grid Splitter keep images aligned? ›
Choose a grid like 3×3 or 3×2; the tool slices your image into tiles sized for Instagram so when uploaded in sequence the profile grid forms one seamless image.
Are images uploaded to a server or kept local? ›
All tools are designed to run locally in your browser. Files are not uploaded to external servers by default — they stay on your device unless you explicitly share them.
Can I export results and what formats are supported? ›
Most image tools export PNG or JPG. Grid tools output multiple tiles (often zipped). Text tools provide copy-to-clipboard and plain-text downloads. Export behavior is shown in each tool UI.
What is Brainrot Translator and Zalgo generator used for? ›
These are novelty/creative tools: Brainrot Translator produces meme-friendly slang variants; Glitched Zalgo creates visually distorted text for horror/edgy stylings. Use them for creative captions and graphics, not for accessibility-critical content.
How does the TikTok Earning Estimator work? ›
It provides rough revenue estimates based on view counts and example CPM ranges. Results are approximate — real earnings depend on region, CPM, and platform specifics.
Which browsers/devices work best with these tools? ›
Modern desktop browsers (Chrome, Edge, Firefox, Safari) provide best performance for large images and exports. Mobile browsers work for quick checks, but desktop is recommended for heavy edits and batch exports.
How do I request a new tool or report an issue? ›
Open an issue or feature request on the repo: github.com/raviosa-ui/smth-ui — include a short description and example images where helpful.
