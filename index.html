Frequently Asked Questions

Why do you need an Invisible Space? ›
Instagram, TikTok, and Facebook often remove normal line breaks. Our invisible Unicode character (U+2800) forces a clean line break so captions keep the spacing you want.
What is the Caption Counter and how does it help? ›
Caption Counter shows character, word, line and emoji counts and compares them to platform limits (Instagram, YouTube, TikTok). Useful for avoiding truncated captions and keeping descriptions under limits.
How accurate is the Safe Zone Overlay? ›
The Safe Zone Overlay approximates typical UI placements (bottom caption bars, right-side buttons). It’s a visual guide — device variations exist, but it prevents the most common placement issues.
When should I use the Full Frame Blur tool? ›
Use Full Frame Blur to add blurred fill behind portrait content when your source aspect ratio doesn’t match the destination (e.g., post a horizontal photo in a vertical feed), or to hide sensitive background details.
What is SVG ASMR Drawing and how does it work? ›
SVG ASMR Drawing lets users upload an SVG vector file. The tool animates stroke drawing (path-by-path) so you can watch the image being drawn. The animation can be recorded locally (screen capture) to create relaxing ASMR-style drawing videos — ideal for shorts and loops.
What is Aura — Digital Sanctuary? ›
Aura is a calming, minimalist browser homepage: it displays a large live clock, current date, daily mindfulness quote (with a 'new quote' button), simulated weather, and an auto-changing gradient background based on time of day. It’s built for gentle, mindful digital breaks.
What does the Digital Detox tool include? ›
The Digital Detox tool provides a printable 'Mindful Moments Offline' worksheet with a habits audit, a 7-day detox calendar, analog activity suggestions, boredom-busters, and phone-jail coupons. It includes print-optimized CSS for clean double-sided A4 prints.
Does the SVG ASMR or drawing tool upload my files? Is it private? ›
All our tools are designed to run locally in your browser and avoid server uploads by default. Uploaded SVGs remain in your browser memory for processing and are not sent to our servers unless you explicitly choose to upload elsewhere.
How do exports and downloads work for image tools? ›
Most image tools export PNG or JPG. Grid splitters export multiple tiles (zipped when necessary). Video-like exports (e.g., SVG animation) require local recording or browser-based capture; we provide guidance in each tool's UI.
Which browsers/devices are recommended? ›
Modern desktop browsers (Chrome, Edge, Firefox, Safari) are best for large images, animation previews and exports. Mobile browsers work for quick checks but desktop is recommended for heavy edits and print/export tasks.
How do I request a new tool, report a bug, or contribute? ›
Open an issue or feature request on the repo: github.com/raviosa-ui/smth-ui. Include a short description and example images or steps to reproduce.
