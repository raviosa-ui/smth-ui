About SocialMediaToolsHub

Small, fast, privacy-minded browser utilities that help creators write, crop, check and ship social content — without uploading files to third-party servers.

We focus on tools you use every day: caption helpers, visual previews, quick exports and creative text effects — built to run locally for speed and privacy.

Our promise

Local-first: most tools run entirely in your browser. Files you upload are processed client-side and not sent to our servers unless you explicitly export/upload elsewhere.

Open & tiny

We keep tools single-file where possible and avoid heavy frameworks — that means faster load times and smaller bundles for creators on slow networks.

Privacy-first

No tracking, no analytics by default. If we add optional telemetry it will be opt-in.

Core tech

Vanilla HTML/CSS/JS, canvas for image work, File API for local exports, and optional tiny libs only when necessary.

Privacy & security

We design tools to run locally whenever possible. Uploaded files are processed client-side using browser APIs and are not stored on our servers. If a future feature requires optional cloud processing you'll be clearly informed and asked to opt in.

Open source: the project is on GitHub — inspect the code, suggest changes, or fork it for your own needs. github.com/raviosa-ui/smth-ui
