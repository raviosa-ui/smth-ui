Frequently Asked Questions

Quick answers about the most used tools. Click a question to open the answer.

What does the Caption Counter do? ›
Caption Counter calculates characters, words, lines, emoji counts and remaining space for platform limits (Instagram captions, YouTube descriptions, etc.). It includes copy and export options.
How does the Safe Zone Overlay help creators? ›
It overlays platform UI "danger zones" (like the right-side buttons and bottom captions) on your frame so you can position subtitles and CTAs where they will remain visible after upload.
What is Full Frame Blur for? ›
Use Full Frame Blur to blur the entire background, create focus on the subject, make thumbnails pop, or hide sensitive details quickly before posting.
How does Hashtag Cleaner work? ›
Paste a hashtag block and the cleaner removes duplicates, trims whitespace, enforces consistent # prefixes and formats the list for easy copy-paste.
What does the YouTube Thumbnail Previewer do? ›
It simulates desktop and mobile thumbnail sizes and shows how text and faces read at small sizes so you can adjust composition and typography before uploading.
How do I use the Instagram Grid Splitter? ›
Upload an image, choose a grid (e.g., 3×3 or 3×2) and export the tiles ready for Instagram upload — ensures edges line up seamlessly on your profile grid.
Are my images uploaded to a server? ›
No — all tools run locally in your browser. Files are not sent to a remote server by default, ensuring privacy for drafts and client work.
Can I export results (images / text)? ›
Yes — many tools offer one-click export: PNG for images, tiled JPGs for grid splits, or plain text/CSV for lists and timestamps.
What if a platform updates its UI? ›
Safe zones approximate common UI layouts; if platforms change, update the overlay tool's presets. We can add additional device presets on request.
Do tools support mobile devices? ›
Yes — the tools are responsive and designed for both desktop and mobile browsers. For image-heavy manipulations, desktop provides more comfort and faster export.
Where can I request a new tool? ›
Use the "Requests" link in the header or open an issue on the repo: https://github.com/raviosa-ui/smth-ui. Provide a short use-case and example images if available.
Do the tools consume a lot of CPU / RAM? ›
Most single-image tools are light. Video or very large images may use more memory — export at common sizes like 1080×1920 for best performance.
